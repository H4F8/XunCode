## Полное описание

**XunCode** — бесплатный редактор кода с открытым исходным кодом для Android.
Настольный опыт программирования прямо в телефоне: движок Monaco Editor (тот же,
что в Visual Studio Code), полноценный терминал Linux и система плагинов.
Root не требуется.

РЕДАКТОР КОДА
• Подсветка синтаксиса для 25+ языков: JavaScript, TypeScript, Python, Dart, Go, Rust, C/C++, Java, Kotlin, PHP, Ruby, Lua, HTML, CSS, SCSS, JSON, YAML, Markdown, Shell, SQL, Swift, XML.
• Автодополнение кода с гибкими настройками: включение, задержка срабатывания, максимальное число подсказок.
• Мини-карта кода, автоотступы, парные скобки, перенос строк.
• Несколько открытых файлов во вкладках с индикацией несохранённых изменений.
• Боковая панель проекта: дерево файлов рабочей директории.
• Палитра команд плагинов с быстрым поиском.
• Статус-бар: позиция курсора, активный язык файла.
• Настройки редактора: размер шрифта, семейство шрифтов (JetBrains Mono, Fira Code, Cascadia Code), размер табуляции, автосохранение.
• Тёмная тема в стиле VS Code и светлая тема на выбор.

ТЕРМИНАЛ LINUX БЕЗ ROOT
• Полноценное пользовательское окружение Alpine Linux через proot — root-доступ не нужен.
• Технология AXS обходит ограничения Android 13+ на исполнение файлов (noexec/W^X) через memfd_create.
• Если Alpine не установлен или не поддерживается устройством — автоматический fallback на системную оболочку.
• Несколько одновременных сессий терминала во вкладках.
• Экранная строка быстрых клавиш: Ctrl, Esc, Tab, стрелки, служебные символы.
• Отдельная сборка с эмулированным root внутри proot — для пакетных менеджеров и инструментов, ожидающих права суперпользователя.

ПЛАГИНЫ
• Установка плагинов из любого публичного GitHub-репозитория с файлами plugin.json и main.js.
• Песочница: каждый плагин выполняется изолированно, с явной моделью разрешений.
• API плагинов на JavaScript: доступ к редактору, файловой системе, HTTP-запросам, запуску процессов терминала, настройкам, хранилищу, поиску по проекту и интерфейсу.
• Управление плагинами без перезапуска приложения: активация, деактивация, перезагрузка, удаление.
• Встроенный маркетплейс: каталог и установка плагинов в пару касаний.
• Режим разработчика: установка плагина из локальной папки или по ссылке.

ЯЗЫКИ ИНТЕРФЕЙСА И СРЕДЫ РАЗРАБОТКИ
• Интерфейс на русском и английском; дополнительные языковые пакеты подключаются простым текстовым файлом.
• Загрузка сред разработки одним нажатием: Python, Node.js, Go, Rust, Ruby, Lua, PHP, Java — или любой свой инструмент по прямой ссылке.

УМНЫЕ ОБНОВЛЕНИЯ
• Приложение само проверяет новые версии через официальные GitHub Releases.
• Обычные обновления не отвлекают: аккуратный красный индикатор у настроек и список изменений от разработчика.
• Критические патчи безопасности честно объясняют причину блокировки текстом разработчика до обновления.
• Определение источника установки: обновления приходят вовремя, без ожидания модерации.
• Работает офлайн: нет интернета — приложение просто продолжает работать.

БЕЗОПАСНОСТЬ И ОТКРЫТЫЙ КОД
• Не собирает персональные данные, не содержит рекламы и трекеров.
• Исходный код открыт под лицензией Apache 2.0: https://github.com/H4F8/XunCode

Скачайте XunCode и программируйте где угодно — в дороге, на паре или в очереди за кофе.
