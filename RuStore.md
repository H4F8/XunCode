## Полное описание

**XunCode** — бесплатный open-source редактор кода для Android. Настольный опыт программирования прямо в телефоне: движок Monaco Editor (тот же, что в Visual Studio Code), полноценный терминал Linux и система плагинов. Root не требуется.

РЕДАКТОР
• Подсветка синтаксиса для 25+ языков: JavaScript, TypeScript, Python, Dart, Go, Rust, C/C++, Java, Kotlin, PHP, Ruby, Lua, HTML, CSS, JSON, YAML, Markdown, Shell, SQL и другие.
• Автодополнение, автоотступы, парные скобки и мини-карта кода.
• Несколько открытых файлов в вкладках, отслеживание несохранённых изменений.
• Боковая панель проектов — навигация по рабочей папке.
• Гибкие настройки: размер шрифта, семейство шрифтов, размер табуляции, перенос строк, автосохранение.

ТЕРМИНАЛ LINUX БЕЗ ROOT
• Полноценное пользовательское окружение Alpine Linux через proot — root-доступ не нужен.
• Технология AXS обходит ограничения Android 13+ на исполнение файлов (noexec/W^X).
• Если Alpine не установлен или не поддерживается — встроенный fallback на системную оболочку.
• Несколько одновременных сессий терминала.
• Экранная строка быстрых клавиш: Ctrl, Esc, Tab, стрелки и символы.

ПЛАГИНЫ
• Установка плагинов из любого публичного GitHub-репозитория с plugin.json и main.js.
• Песочница: каждый плагин выполняется изолированно, с явной моделью разрешений.
• API плагинов: доступ к редактору, файлам, HTTP-запросам, запуску процессов, настройкам и поиску по проекту.
• Встроенный маркетплейс плагинов.

ЯЗЫКИ И ОФОРМЛЕНИЕ
• Интерфейс на русском и английском, подключаемые языковые пакеты.
• Тёмная тема в стиле VS Code.
• Установка сред разработки (Python, Node.js, Go, Rust, Ruby, Lua, PHP, Java) или любого кастомного инструмента по ссылке.

БЕЗОПАСНОСТЬ И АВТОНОМНОСТЬ
• Приложение работает офлайн: интернет нужен только для скачивания плагинов, рантаймов и обновлений.
• Система умных обновлений через GitHub Releases: обычные обновления не отвлекают от работы, а критические патчи безопасности честно объясняют причину блокировки текстом разработчика.
• Определение источника установки: пользователи RuStore получают обновления вовремя, без ожидания модерации.
